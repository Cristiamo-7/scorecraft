# 小雨点跳舞 · 动态曲谱（音块跟唱）

课堂投屏用动态谱。打开 `index.html` 即可，双击就能跑，不联网。

> 本文是**交付给老师的说明文样例**，配套谱例是 `assets/example/score.json`（自编练习曲，可自由使用）。换成自己的歌时照着改对应数字即可。

**`index.html` 是完整的单文件（约 4 MB）**：谱例数据、字体、底图、范唱音频全部内嵌在里面，**只拷这一个文件**到班级电脑（U 盘 / 微信传输 / 局域网都能传）双击即可，不需要旁边放 mp3 和图片，断网也不影响。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | **成品**，单文件动态谱（谱例数据、字体、底图、音频全部内嵌，无外部依赖） |
| `score.json` | **唯一的谱例数据源**（音符、时值、歌词、连音、力度、段落、速度、起唱位置） |
| `score.template.html` | 页面模板，含 `__SCORE_JSON__` / `__TITLE__` / `__SUB__` / `__AUDIO__` 四个占位符 |
| `build.py` | 打包脚本：`score.json` + 模板 → `index.html`（默认内嵌底图与音频；加 `--link` 出外链小体积版） |
| `align.py` | 对拍脚本：从音频自动测出 BPM 与起唱位置，写回 `score.json` |
| `make_font.py` | 字库脚本：按页面用字把开源字体切成子集、内嵌进模板 |
| `check_layout.py` | 版面体检：无头浏览器跑完全曲，查压盖/越界/报错 |
| `fonts/` | 字体源文件（站酷快乐体、Baloo 2，均为 SIL OFL 1.1，可随文件分发） |
| `底图.jpg` | 按歌词意境生成的插画（可换成自己的图，不强制） |
| `范唱.mp3` | 音频（唯一时钟源） |

> `index.html` 是生成物。要改谱请改 `score.json`，再跑 `build.py`，不要直接手改 `index.html`（下次打包会被覆盖）。

## 换一首歌（三步）

```bash
cd ~/Downloads/小雨点跳舞动态谱
# 1) 改 score.json：meta.title / meta.audio / notes 等
# 2) 把新音频拷进本目录，文件名与 meta.audio 一致
python3 align.py --write    # 3) 自动对齐速度与起唱，写回 score.json
python3 make_font.py        # 4) 新歌词里若出现生僻字，重切一次字库
python3 build.py            # 5) 打包成 index.html（底图、音频一起内嵌）
```

> 只想反复调样式、不想每次重算 4 MB 的 base64 时，用 `python3 build.py --link` 出一份外链版（体积小，需要同级目录有 mp3 和底图）。正式上课前再跑一次不带参数的 `python3 build.py`。

- `align.py` 只改 `tempo`、`audioOffset`、`introBeats` 三个数字，**不动你排版好的 JSON 格式**，可以放心反复跑。
- 跑完看两行：
  - `chroma 对齐度` 明显高于 0.083（随机基准）才算对上了；一般 0.3 以上。
  - `音高一致率` 越高越好（≥70% 可用）；如果 `移调` 不是 +0，说明录音比谱面高／低几个半音——页面只显示音级，不影响观看。
- 对不准时：`python3 align.py --tempo 96 --offset 7.2` 人工给定（`offset` 是"第一个音唱出来的秒数"）。
- `build.py` / `align.py` 只用到 Python 3 标准库 + numpy + ffmpeg（macOS 上 `brew install ffmpeg`）。

## 拷到班级电脑（离线）

1. 只拷 `index.html` 一个文件（约 4 MB，U 盘、微云、微信文件传输都行）；不用带 mp3、不用带图片。
2. 班级电脑双击打开，建议用 Chrome / Edge（都自带，无需安装）；首次可能提示"是否允许音频播放"，点允许即可。
3. 按 `F11` 或点右下"全屏"投屏；音箱音量在电脑上调，页面里不自带音量条。
4. 旧电脑/老浏览器如果显示很慢：把 `index.html` 拖进 Chrome 窗口打开，比 IE / 老的 360 兼容模式快得多。
5. 想换底图或图标，点"背景/图标"选图后会**存在那台电脑的浏览器里**（下次打开还在）；换电脑则回到默认。

## 课堂用法

- `▶ 播放` 或 **空格** 播放 / 暂停；**← →** 前后跳 4 拍；**R** 重来。
- **选段**：全曲 / 一句 / 二句 / 三句 / 四句 —— 每句 4 小节，点一次即从那句开头起播，句末自动回跳，可反复练。
- **速度**：1× / 0.75× / 0.5× 慢练，音高不变、音画仍同步。
- **同步 ±**（或 `[` `]`）：半拍内音画有偏差时微调，每步 0.05s，自动记住。
- **形状**：在"气泡（短音圆、长音椭圆）→ 实心方糖 → 果冻"之间循环，选过会记住。
- **配色**：柔和 / 暖秋 / 糖果 / 年画 四套低饱和配色循环切换，同样会记住。
- **图标**：默认是一枚金色八分音符；点一下可换成自己的图片（PNG/JPG，自动缩到 160px 存本地）；`meta.sun` 可指定谱例自带图标。
- **背景**：点"背景"选一张图（横版 16:9 最好看），自动缩放到合适尺寸存本地；页面底色随之换成这张图，并在图上压一层纸色蒙版保证谱面文字看得清。
- **还原**：把图标和背景一次性恢复成默认（设过自定义后才会出现）。
- **全屏**（或 F11）：投屏用；录屏用 OBS / 剪映截取 1920×1080 即可。

## 谱面设计

- 上方是**音级轴 + 彩色音块**：左侧每一级是一张圆角小卡片（数字 + do/re/mi 唱名，当前音那格会亮起来）；纵向是音高，横向是时间；音级配色全曲固定（1 珊瑚 / 2 杏 / 3 米黄 / 4 抹茶 / 5 湖蓝 / 6 雾蓝 / 7 藕荷）。示例曲用到 6 个音级（低音 5 与中音 1 2 3 5 6），舞台按实际出现的音高**自动分行**，行数越多行距越紧。
- **音块形状默认"气泡"**：一拍以内的音是**正圆**，圆心正落在拍点上；两拍以上的长音是**椭圆（胶囊）**，从拍点起铺满时值。切到"实心/果冻"则统一为方糖形状。
- **歌词就压在各自音块的正下方**，同一音级行的字排在**同一条水平线**上（不会因为音块大小参差而高低跳），字号随音级行高自适应；唱到哪个字，那个字放大并变成该音级的深色——学生眼睛在音块和字之间不用来回找。休止（`0`）不在舞台上画块，只由下方简谱表达。
- 虚线指针固定 28%，谱面向左滚动；当前音发光放大。
- **小音符沿着旋律蹦跳**：它先**站在当前音块上跟着谱面走**（长音时最多落后指针 52px），在这个音快结束时起跳，**落在下一拍音块上的那一刻正好是拍点**（起跳窗口最长 0.62 拍）。
- 跳跃轨迹按音高走向分两种：**上行大跳**先快速起跳、弧顶在上方轻轻"悬"一下再落稳（附带 −7° 后仰）；**下行**只留 3~7px 滞空、先浮后坠，像顺着旋律线滑下去（+8° 前倾）。同音反复则是小跳。
- 起跳瞬间轻微拉长、落地瞬间压扁再阻尼回弹，落地同时炸出光圈、金色火星和拖影；空中每 54ms 留一枚残影（跨八度的大跳加密到 32ms、残影更大），所以快跳也有拖尾，不会是"瞬移"。
- 音符坐在音块上沿（只压 1px 边，不挡数字），符头对准虚线指针；最上层音放不下时贴着顶边，不会往下压到下一行。
- **休止符不是"音变低"**：遇到 0（休止）时精灵**停在最后一个实音的高度不动**（不呼吸、不弹跳），只淡到 42% 表示"声音停了"；休止结束、下一个音进来的那一瞬才重新起跳（窗口收短到 0.38 拍）。前奏/尾奏淡化到 26%/14%。
- **前奏显示 4-3-2-1 倒计时**（拍数由 `meta.introBeats` 决定，示例为 8 拍），提示学生准备起唱。
- 下方**简谱同步面板**按句分页（每句 4 小节一行），符头一律对准自己的拍位（小节线后留空隙）；小节线、延音线、低音点、一字多音连音弧，当前音实时标红；句末换行。**简谱数字 31px、歌词 23px**，是按"坐后排也看得清"定的尺寸；小节线只画到减时线下沿，不穿到歌词里。
- **连音弧架在音符上方**：两端正好落在首末两个符头的正上方（不偏移、不压住数字），弧高 5~11px 随跨度自适应；组里有高八度点时整条再抬高 6px 让开圆点。示例曲有三处一字多音（"来""谣""呀"）。
- **低音点的位置按谱例惯例**：没有减时线时，低音小圆点就在数字正下方；有减时线时，圆点移到**减时线的下方**（数字 → 减时线 → 圆点，从上到下）。十六分音符叠两条减时线时，圆点落在第二条线下方。
- **减时线成组**：八分音符按拍成组，一组连成一条，组间留空隙，不跨小节线。
- 力度记号 `mp / p / f` 与 `渐慢` 标在对应小节上方；每句开头小节线加重，便于数"一句四小节"。
- **整体尺寸按"阶梯教室后排也能看清"调过**：音块行间只留 8px 空隙（块高约 39px，短音圆约 27px），块里音级数字 24px；顶部标题 34px；左侧音级卡片 50×40px、数字 18px。改尺寸只需要动 `score.template.html` 里的 `--dig-h` 与 `buildAxis()` 的 `laneTop / bottomPad / noteH`，改完必须重跑 `check_layout.py`。

## 字体与底图

- **字体**：全页用**站酷快乐体**（圆润、有童趣的手写感），数字（音块里的音级、简谱数字、时间码）用**Baloo 2** 的圆体数字，比正文字体更扎实好认。
  两套字体都是 SIL OFL 1.1 开源授权，已按本页用到的字**切成子集（约 50KB）内嵌进 HTML**——所以断网、拷到别的电脑、发给同事都不会掉字或变回系统字体。
- 换歌后如果某个字显示成了系统字体，跑一次 `python3 make_font.py` 重切字库即可（需要 `pip install fonttools brotli`）。
- **底图**：按歌词意境生成一张横向 16:9 的插画（中央留白给音块），写进 `meta.background`；谱面区会压一层米白径向蒙版，字看得清、画也透得出来。
  示例谱例没带底图，所以是素纸色。想要别的风格，点"背景"换图，或把图片放进工作目录并写进 `meta.background`（**换完要重跑 `python3 build.py` 才会内嵌进 index.html**）。

## 谱例来源与对拍依据

- 示例谱例是**为演示格式而自编的练习曲**：`1=C`、`4/4`、小快板 ♩=96，16 小节 64 拍，4 句各 16 拍。
- 词曲均为示例而作，可自由改写、分发，不涉及任何教材或出版物。
- 结构上刻意覆盖了这些情况，方便照抄：八分音符成组、四分/二分/全音符长音、跨小节休止、低八度（5̣）、一字多音三处（"来""谣""呀"）、力度记号 `mp / p / f` 与结尾 `渐慢`。
- 换自己的歌时，`tempo` 与 `audioOffset` 交给 `align.py` 算，不要手猜；它靠"人声基频跳变点"与"谱面音高跳变点"做全局扫描 + 最小二乘，报告里会给出参与拟合的点数、残差 RMS 与 chroma 对齐度。
- **前奏与尾奏完整播放**：这两段没有歌声，所以不做音符识别（不生成音块、不高亮），但音频照放到底；尾奏时谱面停在终止线，右上角提示"谱面已唱完，乐曲继续"，播完才停。

## 想改谱怎么办

1. 改 `score.json`：
   - `notes[]`：`degree`（1~7，0 为休止）、`octave`（0 中音，-1 低音，1 高音）、`startBeat`（从 0 起，四分音符 = 1 拍）、`durBeats`、`lyric`（一个字写一次，一字多音只标第一个）。
   - `slurs[]`：`melisma` 为一字多音（简谱上画弧），`phrase` 为乐句弧。
   - `sections[]`：每句的起止拍与整句歌词（选段用），段长保持 16 拍。
   - `dynamics[]`：`beat` + `text`，`kind` 为 `dyn`（力度）或 `tempo`（速度用语）。
   - `meta.sun`（可选）：音符图标的默认图片文件名；用户在页面上传的图标优先。
   - `meta.background`（可选）：背景图的默认文件名；用户在页面上传的背景优先。
   - `meta.skin`（可选）：`bubble` / `solid` / `jelly`，默认 `bubble`。
   - `meta.palette`（可选）：`soft` / `autumn` / `candy` / `nianhua`，默认 `soft`。
2. 跑 `python3 build.py` 重新打包；脚本会顺手校验字段、重叠音、音频时长是否够唱完。
3. 跑 `python3 check_layout.py index.html` 体检版面，全绿再交付。
