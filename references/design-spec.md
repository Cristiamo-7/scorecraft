# 视觉与动效规范（对应 assets/template/score.template.html）

改样式只动模板，不要手改 `index.html`（每次 `build.py` 都会被覆盖）。下面所有数值都是**投屏可读版**的定稿值，改前先读「改尺寸的三处联动」。

## 一、画布与栅格

```
#frame   1280×720，圆角 14，padding 6px 22px 8px
         grid-template-rows: 52px | 1fr | 124px | 54px
         → 抬头 / 谱面舞台 / 简谱面板 / 控制条
         整体 transform: scale(min(vw/1280, vh/720)) 居中缩放，所以「字号够不够大」是相对于 720 高的比例问题
```

| 区块 | 高度 | 内容 |
|---|---|---|
| header | 52 | 标题 34px（左侧 11×30 圆角色条）+ 副标题 13px；右侧 5 个胶囊 13.5px |
| stage | 1fr ≈ 476 | 左侧音级轴 68px + 谱面 viewport |
| jianpu | 124（含 margin-top 4） | 每句一页的简谱同步面板 |
| controls | 54 | 播放/选段/速度/同步/形状/配色/图标/背景/全屏 + 时间码（**这行最挤，1280 宽已用 1236px，不要再放大按钮**） |

## 二、谱面舞台

```
laneTop = 32      // 顶部留白，够跳动音符站上去不被切
bottomPad = 22    // 底部留白，够最低一行音块的歌词
laneH = (viewportH - laneTop - bottomPad) / laneCount
noteH = min(40, laneH - 8)          // 只留 8px 行间空隙
cardH = min(44, max(26, laneH - 6)) // 左侧音级卡片高度
PB = 60           // 每拍 60px
```

- 音级轴卡片：宽 50、圆角 12、数字 18px + 唱名 9px；当前音 `scale(1.14)` + 白色描边光晕。
- 音块：`border 2.6px`，外圈 `0 0 0 3px rgba(255,253,248,.72)` + 柔和投影；块内数字 **24px**（窄块 17px，`ww < 32` 时算窄）。
- 「气泡」形状（默认）：`durBeats ≤ 1` → 正圆，直径 `min(noteH, max(27, dur*PB-8))`，圆心压在拍点上；`durBeats > 1` → 胶囊，宽 `dur*PB-12`，从拍点铺满，圆心在块中。八分音符 27px、四分 39px，这是**时值编码**，别为了整齐把两者做成一样大。
- 当前音：填充换成描边深色、白字、`translateY(-2px) scale(1.07)`、外发光；已唱过的块 `opacity:.58`。
- 歌词：`top = cy + noteH/2 + 2`（**用 noteH 而不是块自身高度**，这样同一音级行的字排在同一条水平线上，不会大小块参差），字号 `clamp(15, 20, round(laneH*0.41))`（本曲 19px），颜色取该音级深色 + 三层白描边保证压在彩块上也清晰；当前字放大 1.24 并变描边色。
- 休止符不画块：`.blk.rest{display:none}`，只在下方简谱留 `0`。
- 底色：viewport 上叠 `radial-gradient(120% 90% at 46% 42%, rgba(255,253,248,.90) → .50)`，让水彩底图透出来又不干扰读谱。

## 三、跳动音符（这是本模板的招牌，改之前先把物理参数读懂）

```
HOP_LIFT = 22    // 上行跳跃附加弧高上限
HOP_MAX  = 0.62  // 一次起跳最长占 0.62 拍；休止后重启收紧到 0.38
LAG_MAX  = 52    // 长音时最多落后指针 52px，保证始终踩在块上
SPR_OX   = 6     // 符头对准虚线的水平微调
BOUNCE_T = 0.26  // 落地压扁回弹时长
```

- 落点：`contactY = cy - hh/2 - 18`（精灵中心），夹到最小 1，最上层贴着顶边不压下一行。
- 时间：在这个音快结束时起跳，**落在下一拍音块上的瞬间正好是拍点**——`t0 = nextStart - hb`。
- 轨迹：上行 `pv = 1-(1-hp)^1.55`（起跳快、落点稳）+ 弧高 `min(22, 6+|dy|*0.42)`，后仰 −7°；下行 `pv = hp^1.45`（先浮后坠）+ 滞空 ≤7px，前倾 +8°。
- 挤压：起跳拉长、落地压扁，`exp(-9t)·cos(2π·2.6t)` 阻尼回弹；静止时 −1.4~+1.6px 呼吸。
- 残影：原地淡出，每 54ms 一枚；`|dy| > 80` 的大跳加密到 32ms、更大；落地再炸光圈 + 7 颗火星 + 3 层 ghost。
- **休止符不是「音变低」**：锚点退回最后一个实音，精灵停住（不呼吸、不弹跳），只淡到 `opacity .42`。
- 顶边保护：`sunEl.top = max(20, sprY + lift)`——大跳弧高再大也不会被谱面上沿切掉脑袋。改这个 clamp 前先想清楚「宁可贴顶也别切头」。
- 前奏：`b < 0` 时精灵在指针左侧待命轻浮；`b > 总拍数` 时淡到 14%。

## 四、简谱面板

`--dig-h` 是**唯一联动变量**：数字视觉高度。低音点、减时线、歌词、小节线全靠它定位，改字号只改这一个地方（本版 26px，对应 31px 数字）。

| 元素 | 值 | 备注 |
|---|---|---|
| 数字 | 31px Baloo 800，`top:4px`，`line-height:1` | 当前音标红并 `scale(1.14)` |
| 休止 0 | 32px，**必须 `line-height:1`** | 否则 0 会比数字低 4px |
| 低音点 | 5px 圆点；无减时线 `dig-h+1`；一条线 `dig-h+9`；两条线 `dig-h+15` | 有点顺序：数字 → 减时线 → 圆点 |
| 高八度点 | `top: -dig-h*0.30` | 所以 `.jp-line` 要 `top:6px` 给它留位置 |
| 减时线 | 2px，`top: 4+dig-h+2`；第二条 +8 | 按拍成组，一组一条，不跨小节线 |
| 歌词 | 23px，`top: 6+dig-h+21` | 当前字标红放大 1.12 |
| 小节线 | `height: 4+dig-h+16` | **只画到减时线下沿**，不穿到歌词里 |
| 连音弧 | SVG，`y=3`（有高八度点则 −3），弧高 `min(11, 5+跨度*0.05)` | 两端落在首末符头**正上方**，不接触数字 |
| 面板 | `grid-template-rows: 16px 1fr`，`margin-top:4px` | 页头 13px + 翻页按钮 24×21 |

每页 16 拍（4 小节），`UNIT = 73` px/拍，左侧留 18px、小节线后留 15px 空隙。

## 五、配色与皮肤

- 七个音级三色一组（淡底 / 描边 / 深字）：`--d1-* … --d7-*`，休止 `--d0-*`。**全部低饱和**，投屏不刺眼。
- 四套配色：`soft`（默认，珊瑚/杏/米黄/抹茶/湖蓝/雾蓝/藕荷）、`autumn`、`candy`、`nianhua`。
- 三种形状：`bubble`（默认）/`solid`（color-mix 压深 84%+`#5b4133`）/`jelly`（上下渐变 + 内高光）。
- 切换存 `localStorage`：`xfjh-skin` / `xfjh-pal` / `xfjh-bg` / `xfjh-sun-icon` / `xfjh-sync-v{offsetVersion}`。

## 六、字体

- 中文：站酷快乐体（`--font-fun`，童趣、不严肃）；数字：Baloo 2 wght 800（`--font-num`，圆体数字比正文更扎实）。
- 两套都是 SIL OFL 1.1，源文件在 `fonts/`，`make_font.py` 按「score.json 的歌词/段落/meta + 模板里的中文 + ASCII」切子集后 base64 内嵌（约 49KB + 4KB）。
- **换歌必须重跑 `make_font.py`**，否则新歌词里的字会掉回系统字体。

## 七、改尺寸的三处联动（最常踩的坑）

1. `--dig-h` 改了 → 简谱四项（点/线/歌词/小节线）自动跟，但 `.jp-n` / `.jp-rest` 的 `height:46px` 与面板行高 124px 要一起核对（跑 `check_layout.py` 就知道有没有越界）。
2. `noteH` 改了 → 音级行更挤，歌词可能压到下一行音块（`check_layout.py` 会报「歌词压音块」）；块内数字 24px 相对 39px 块刚好，块再小就得降到 22px。
3. 抬头/面板/控制条任一行高度变了 → 1fr 会变，`laneH` 变，九行音级块的尺寸全变；改完必须重跑体检脚本。
